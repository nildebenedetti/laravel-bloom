# Bloom

## Journaling & Milestone Tracking Web App

The project consists of a full-stack web platform for tracking and visualizing personal milestones (*Journaling & Milestone Tracking*). The application combines a decoupled architecture—a Laravel RESTful backend and a React Single Page Application (SPA)—to provide both a public exploratory experience (*Blooming Meadow*) and an advanced private suite for managing, visually exploring, and quantitatively analyzing personal achievements.
